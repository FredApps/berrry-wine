# Full DirectX7 object table and TickCount

The original DirectX7 typelib declares55 methods after IUnknown:58 slots total. Existing factory allocated7, although JigSawedME reaches TickCount at slot44 after successfully loading its image. This change preserves every existing API row and adds a distinct complete58-slot table. ABI-correct existing QI/refcount/DirectDrawCreate/DirectSoundCreate/DirectInputCreate handlers are retained through aliases. Other methods return E_NOTIMPL with their exact stdcall cleanup, including GetDDEnum at5 and DirectInputCreate at10. TickCount writes the existing guest millisecond clock to its mapped LONG output and returns HRESULT; it validates all output pages before mutation.

Private before/candidate real-WASM validation passed: candidate factory58slots, TickCount actualthunk/ESP12, two clockvalues, sparse output, null/wrapping pointer failure, canaries, unsupportedABI and refcounts. Before control cannot resolve slot44 as a COM thunk. That test allocation result does not prove the original browser's exact slot44 pointer. Production fullbuild gates and ordinary gameplay remain pending. The test is automatically in the unit tier by existing naming convention.
